A living desktop wallpaper — a serene, cosmic night sky with twinkling stars and shooting stars streaking by at random intervals. Ported from the Spicetify **StarryNight** theme into a single standalone HTML file.

## About

StarryNight transforms your desktop into a serene night sky. Watch as stars twinkle softly across a deep, cosmic background while shooting stars streak by at random intervals, creating a peaceful, ever-changing scene.

Originally designed as a Spotify theme by Brandon Chen and Julissa Laignelet for Spicetify, this version was ported from the original theme files into a single standalone HTML file. All Spotify/Spicetify-specific functions were removed and adapted so it works as a living desktop wallpaper, with no music player or Spicetify installation required.

Perfect for anyone who wants a calm, minimal, and slightly magical backdrop for their workspace.

## How to use

1. Download `indexblue.html` from this repository
2. Open it with an HTML wallpaper app (Any wallpaper app that suports html files) — add a new "Web" wallpaper and point it to the file)
3. Enjoy your new desktop background
